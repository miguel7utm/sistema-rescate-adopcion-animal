
# UI Kit - Rescate Animal

## Descripción

Esta biblioteca de componentes UI contiene estilos reutilizables desarrollados con CSS3 para el Sistema de Control de Rescate y Adopción Animal.

Su propósito es mantener una presentación uniforme en las interfaces del sistema y facilitar su reutilización de botones, formularios, tarjetas y etiquetas.

## Archivos del proyecto

- `index.html`: página de demostración de los componentes.
- `style.css`: hoja de estilos con las variables y clases reutilizables.
- `README.md`: guía básica de utilización.

## Componentes disponibles

### 1. Botones

- `.btn .btn-primary`: botón principal.
- `.btn .btn-secondary`: botón secundario.
- `.btn .btn-danger`: botón de peligro.

### 2. Formularios

Los campos de texto utilizan `input` y las listas desplegables utilizan `select`. Ambos reciben estilos mediante las clases y selectores definidos en `style.css`.

### 3. Tarjetas

- `.tarjeta`: contenedor de información.
- `.tarjeta-contenido`: espacio interno de la tarjeta.

### 4. Etiquetas

- `.badge-alta`: urgencia alta.
- `.badge-media`: urgencia media.
- `.badge-baja`: urgencia baja.
- `.badge-estado`: estado rescatado.
- `.badge-tratamiento`: estado en tratamiento.
- `.badge-adopcion`: estado en adopción.

## Uso de la biblioteca

1. Crear un documento HTML.
2. Vincular la hoja de estilos con:

   `<link rel="stylesheet" href="style.css">`

3. Utilizar las clases CSS disponibles en los elementos HTML.
4. Consultar `index.html` para observar ejemplos de los componentes.
